# File Architecture Index

This file records the purpose of project files as implementation progresses.

## Confirmed Implementation Decisions

- The Vite React TypeScript app is initialized directly in the project root.
- `memory-bank/@architecture.md` remains the mandatory AI-readable architecture source.
- This `memory-bank/architecture.md` file is the file-purpose index and should be updated as files are created or responsibilities change.
- Character descriptions, relationship descriptions, and UI text should use concise original wording.
- The first version must not use official manga/anime screenshots or unauthorized visual assets.
- The first version uses abstract graph visuals, original UI styling, text labels, and CSS/Cytoscape styling.
- Initial collectible triggers:
  - Discovering the Jonathan and Dio fate/rivalry relationship.
  - Exploring the Joestar bloodline connection.
  - Selecting or revealing the Gyro and Johnny golden rotation relationship.

## Current Source Documents

- `memory-bank/game-design-document.md`: Product design, user experience, visual rules, interactions, and acceptance criteria.
- `memory-bank/tech-stack.md`: Recommended stack, forbidden first-version technologies, and upgrade path.
- `memory-bank/implementation-plan.md`: Step-by-step implementation plan with validation requirements.
- `memory-bank/progress.md`: Progress log for completed implementation steps.
- `memory-bank/@architecture.md`: Mandatory source of truth for architecture rules and implementation boundaries.
- `memory-bank/@game-design-document.md`: Mandatory source copy of the design document for AI rules.
- `memory-bank/@tech-stack.md`: Mandatory source copy of the technical stack recommendation for AI rules.

## Root Files

- `package.json`: Project metadata, npm scripts, runtime dependencies, and development dependencies.
- `package-lock.json`: Locked dependency versions generated by npm.
- `index.html`: Vite HTML entry point.
- `public/avatars/*.svg`: Original avatar-style SVG portraits used as graph node images.
- `vite.config.ts`: Vite configuration with React plugin.
- `.github/workflows/deploy.yml`: GitHub Actions workflow that uploads the committed `dist` artifact to GitHub Pages.
- `vitest.config.ts`: Vitest configuration limited to unit tests under `src`.
- `playwright.config.ts`: Playwright configuration for desktop and mobile smoke tests.
- `tsconfig.json`: TypeScript project references.
- `tsconfig.app.json`: TypeScript configuration for browser application code.
- `tsconfig.node.json`: TypeScript configuration for tooling configuration files.
- `game-design-document.md`: Root copy of the product design document.
- `tech-stack.md`: Root copy of the recommended technology stack.
- `implementation-plan.md`: Root copy of the implementation plan.

## Source Files

- `src/main.tsx`: React entry point that mounts the application and imports global styles.
- `src/vite-env.d.ts`: Vite client type declarations for CSS and assets.
- `src/app/App.tsx`: Application shell that composes top-level modules only.
- `src/app/App.module.css`: Application shell layout styles.
- `src/app/AppProviders.tsx`: Top-level provider composition.
- `src/styles/tokens.css`: Shared design tokens for colors, spacing, and radii.
- `src/styles/global.css`: Global baseline styles and token import.

## Component Files

- `src/components/FilterBar/FilterBar.tsx`: Search, part filter, relationship filter, and reset controls.
- `src/components/FilterBar/FilterBar.module.css`: Filter bar component styles.
- `src/components/GraphCanvas/GraphCanvas.tsx`: Cytoscape lifecycle, graph rendering, and graph event binding.
- `src/components/GraphCanvas/GraphCanvas.module.css`: Graph canvas layout styles.
- `src/components/GraphCanvas/cytoscapeStyles.ts`: Cytoscape stylesheet rules for nodes and relationships.
- `src/components/CharacterPanel/CharacterPanel.tsx`: Character detail and empty-state panel.
- `src/components/CharacterPanel/CharacterPanel.module.css`: Detail panel styles.
- `src/components/Legend/Legend.tsx`: Visual legend for node shapes and relationship lines.
- `src/components/Legend/Legend.module.css`: Legend styles.
- `src/components/CollectiblesBar/CollectiblesBar.tsx`: Saint corpse collectible progress display.
- `src/components/CollectiblesBar/CollectiblesBar.module.css`: Collectible progress styles.
- `src/components/StatusBar/StatusBar.tsx`: Current view, visible node count, and relationship count.
- `src/components/StatusBar/StatusBar.module.css`: Status bar styles.

## Data Files

- `src/data/characters.json`: First-version static character data.
- `src/data/relationships.json`: First-version static relationship data.
- `src/data/collectibles.json`: Nine saint corpse collectibles and trigger definitions.

## Domain Files

- `src/domain/types.ts`: Shared TypeScript domain types.
- `src/domain/schema.ts`: Zod schemas, bundled data validation, and relationship endpoint validation.
- `src/domain/filters.ts`: Search, part filtering, and relationship type filtering logic.
- `src/domain/graph.ts`: Conversion from validated app data to Cytoscape elements and character relationship lookup helpers.
- `src/domain/collectibles.ts`: Collectible trigger detection and merge logic.

## Hook Files

- `src/hooks/useAppState.tsx`: Shared app state context for filters, selection, view, and discovered collectibles.
- `src/hooks/useCollectibles.ts`: Collectible state integration and trigger helper.

## Test Files

- `src/tests/project.test.ts`: Baseline test environment verification.
- `src/tests/schema.test.ts`: Data validation tests.
- `src/tests/filters.test.ts`: Search and filtering tests.
- `src/tests/graph.test.ts`: Cytoscape element conversion tests.
- `src/tests/collectibles.test.ts`: Collectible trigger tests.
- `tests/e2e/smoke.spec.ts`: Playwright desktop and mobile smoke tests.
